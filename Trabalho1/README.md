## Análise Semântica:


### Como rodar?
Você pode rodar instalando **Python3** na sua máquina, e rodar o seguinte comando:
```shell
python3 main.py
```

Caso você tenha o **Docker** instalado, e preferir, você pode rodar o projeto "conteinerizado" com:
```shell
docker compose up -d --build
docker exec -it compiladores-1 /bin/bash #Lembrando, que você pode trocar o nome do container
```

Quando o terminal abrir, você poderá rodar o projeto normalmente.

> Para definir uma ***entrada***, é só colocar um bloco de código no arquivo **__tests\__/input.txt**.
